# Licensing decision — open

**No license has been chosen for this repository.** This file records the decision as open; it is not
a license and grants nothing.

## Current state

- There is no `LICENSE` file and no `license` field in `package.json`.
- `package.json` sets `"private": true`, so the package cannot be published to npm by accident.
- Absent a license, default copyright applies: the repository owner retains all rights, and no one
  else has permission to use, copy, modify, or distribute the code beyond what applicable law allows.
- Contributions are **not** accepted while this decision is open. A contribution without a chosen
  inbound license cannot be merged safely.

## What must be decided

The repository owner must choose, explicitly:

1. Whether the project is open source, source-available, or proprietary.
2. The exact license text and its version, if any.
3. Whether contributions are accepted, and under which inbound terms (for example a DCO or CLA).
4. Whether the npm package becomes public, and under which name and scope.

Until then, this repository should be treated as private work published in a public place for
review, not as a grant of rights.

## What this file must not become

Do not replace this file with an invented license, a "license: see LICENSE" pointer without a
LICENSE, or a permissive notice added by a tool. Choosing a license is the owner's decision, not an
implementation detail.
